# records-data

The release schedule used by Syngularail Records: official albums, singles and EPs coming out in Japan and worldwide,
built twice a week from the [MusicBrainz](https://musicbrainz.org) core data dump, which is released under
[CC0](https://creativecommons.org/publicdomain/zero/1.0/). Served at `https://tayu1016.github.io/records-data/releases-jp.json`
and `releases-intl.json`.
